# Setlist

Personal setlist tool: paste a list of songs and get them in order with the key on top, ready to print.

Lyrics are stored only in your own browser (localStorage) — nothing is stored in this repository.

Keys: [GetSongBPM.com](https://getsongbpm.com) · Lyrics: your own library, [LRCLIB](https://lrclib.net) (optional).
