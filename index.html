Setlist & Στίχοι

Ανοίγει το πρώτο αποτέλεσμα για κάθε τραγούδι. Την πρώτη φορά ο browser μπορεί να ρωτήσει αν επιτρέπεις τα αναδυόμενα παράθυρα. Πάτα «Να επιτρέπονται πάντα».

Η αναζήτηση αγνοεί τόνους και κεφαλαία. Αρκεί και σκέτος ο τίτλος.

Γράψε μια λίστα και πάτα «Δημιουργία».

Μέγεθος γραμμάτων

    Νέο τραγούδι
    Αναζήτηση στίχων ↗ Αναζήτηση τονικότητας ↗
    LRCLIB (δωρεάν, χωρίς λογαριασμό)

    Ανοιχτή βάση στίχων που ανεβάζουν οι χρήστες της. Φέρνει ολόκληρους στίχους, αλλά δεν έχουν άδεια από τους δημιουργούς. Χρησιμοποίησέ την μόνο για προσωπική χρήση.

    GetSongBPM (αυτόματη τονικότητα)

    Δωρεάν. Φτιάξε λογαριασμό στο getsongbpm.com/api και βάλε εδώ το API key. Τα τραγούδια χωρίς τονικότητα θα παίρνουν αυτόματα μία (σημειωμένη με «auto»).

    Musixmatch (αυτόματοι στίχοι)

    Αναζητά αυτόματα ολόκληρους στίχους στο Musixmatch. Δεν χρειάζεται API key.

    Αντίγραφο ασφαλείας

    Η βιβλιοθήκη αποθηκεύεται μόνο σε αυτόν τον browser. Αν καθαρίσεις τα δεδομένα του ή αλλάξεις συσκευή, χάνεται. Κατέβαζε αντίγραφο συχνά.

    Η επαναφορά συγχωνεύει τα τραγούδια με όσα έχεις ήδη. Αν ένα τραγούδι υπάρχει ήδη, κρατάει την έκδοση από το αρχείο.

    Τονικότητες: GetSongBPM.com
